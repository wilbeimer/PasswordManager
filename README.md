# Password Manager

A full-stack password manager built with Python and JavaScript that allows users to securely store, generate, and manage passwords.

## Features

- Secure password storage
- Password generation
- Browser extension integration
- Session timeout
- REST API
- SQLite database

## Tech Stack

- Python
- Flask
- SQLAlchemy
- JavaScript
- HTML/CSS

## Future Work

- User authentication
- End-to-end encryption
